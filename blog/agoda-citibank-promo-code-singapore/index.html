How to Apply the Citibank Agoda Discount Step by Step

The booking process is straightforward since no code entry is involved.

  1. Go to www.agoda.com/citibanksg - not the main Agoda homepage. This dedicated link activates the Citi partnership discount.
  2. Search for your hotel and dates. On the search results page, look for the "Coupon Applicable" tag on room listings - only tagged rooms receive the Citibank discount.
