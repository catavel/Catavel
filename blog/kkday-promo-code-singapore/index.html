Frequently Asked Questions - KKday Promo Code Singapore

Can I combine a KKday promo code with auto-deals?
In some cases, yes. Auto-deals like Cherry Blossom discounts or Singapore attraction pricing are built into the listed price, so a promo code may apply on top. The best approach is to add to cart and test the code at checkout - KKday will show if the code is compatible or not. Don't assume they stack; verify before completing payment.

Do I need a DBS card to use DBSKKDTOURS and DBSTHUJUN?
Yes. Both DBS codes are card-linked and require you to complete payment with a DBS or POSB debit or credit card. The promo code entry will work, but the discount will only finalize when DBS/POSB is selected as your payment method. Using another card will void the discount.

Is the F26 app code valid for all KKday experiences?
F26 is a new-user code available on the KKday mobile app only - it's not valid on the desktop website. It applies to most experience categories, but may exclude certain promotions that are already heavily discounted. Check the terms shown when you apply the code in-app before confirming.

Can I use KKday promo codes for flights or hotels?
No. KKday is a tours and experiences platform - it does not sell flights or standalone hotel bookings. All promo codes listed here apply to activities, attraction tickets, day tours, private charters, and travel passes. For flights and hotels, check our Trip.com and Expedia promo code pages.

What is the difference between manual promo codes and KKday auto-deals?
Manual codes (like SPRPC10 or DBSTHUJUN) require you to enter a code at checkout to activate the discount. Auto-deals are promotions where the discounted price is already applied to the listed price - no code entry needed. Both types are valid discounts. Auto-deals are often simpler but may have fewer choices than the full catalog.

Are KKday Singapore codes different from global KKday codes?
Some codes are region-specific - OVE7 for example covers Australia, NZ, and Singapore tours only. Others like SPRMOVE7 and F26 are globally applicable across all KKday destinations. DBS codes are Singapore-market specific as they require a Singapore-issued DBS or POSB card. Always check the listed regions before assuming a code will work on your specific booking.
